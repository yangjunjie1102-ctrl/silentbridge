# SilentBridge

Real-time AI captioning tool designed for hearing-impaired users.

## Features

- Real-time speech-to-text
- Classroom accessibility support
- Low-latency caption display
- AI-assisted communication

## Tech Stack

- C++
- Whisper.cpp
- Qt
- CMake

## Why I Built This

As a hearing-impaired CS student, I want to build tools that improve accessibility in learning and communication.

## Project Status

Currently in early development.
